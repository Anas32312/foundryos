# Create Landing Page

Edit `app/page.tsx` in the generated site. Keep one `<main>`, a skip link, and a heading that matches `site.config.json` `name`.

1. Put the offer in the first paragraph under the title.
2. Replace the three cards with the proof points. If proof is missing, leave three short placeholders that say what to fill in.
3. Make the contact region one action: a `mailto:` link or a normal URL from the next step. Do not add a form backend.
4. Keep the page readable without JavaScript and without remote fonts.
5. Run `npm run lint` and `npm run build`.
